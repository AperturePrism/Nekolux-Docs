# Nekolux docs — 主动退出搜索引擎索引
#
# 当前阶段：允许抓取，靠页面里的 <meta name="robots" content="noindex">
# 让搜索引擎把已收录的页面移除。
#
# 为什么这里不写 Disallow：
#   Disallow 会让爬虫无法访问页面，也就读不到 noindex 标记，
#   结果是**已收录的页面会一直留在索引里**（只剩一个没有摘要的空条目）。
#   正确顺序是先 noindex 等收录清空，再回来把 Allow 改成 Disallow。
#
# 等 Bing / Google 的「已收录页面数」降到 0 后，把下面两行改成：
#   User-agent: *
#   Disallow: /

User-agent: *
Allow: /
